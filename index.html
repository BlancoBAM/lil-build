Repository Sources Configuration

Run the following commands on your Lilith Linux installation or compatible Ubuntu 26.04+ system to configure secure APT sources and prioritize the overlay repository.

1 Download and Import GPG Archive Key
curl -fsSL https://packages.lilithlinux.org/lilith-archive-keyring.gpg | sudo gpg --dearmor -o /usr/share/keyrings/lilith-archive-keyring.gpg
2 Add Lilith Repository to Sources List
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/lilith-archive-keyring.gpg] https://packages.lilithlinux.org stable core xtra" | sudo tee /etc/apt/sources.list.d/lilith.list
3 Configure APT Pinning Priority (Prefer Lilith Overlay)
sudo tee /etc/apt/preferences.d/lilith-priority << 'EOF' Package: * Pin: origin packages.lilithlinux.org Pin-Priority: 900 Package: * Pin: origin "" Pin-Priority: 500 EOF
4 Synchronize Indexes & Install Core Utility
sudo apt update && sudo apt install -y hellfire

Lilith Linux Help Manual

Read documentation regarding system structure, custom tools, desktop customization configurations, and package orchestration architectures.

Overview

Lilith Linux is a customization layer and package environment built on Ubuntu Resolute. It features a security-focused desktop, integrated AI assistants, and a thin meta-repository architecture that eliminates the need to mirror large package binaries.

Keyboard Shortcuts

Lilith uses optimized workspace shortcuts for navigation:

  • Super + T: Open Hyper terminal
  • Super + B: Open HellFire web browser
  • Super + D: Toggle App Launcher
  • Super + Arrow Keys: Snap windows and switch workspaces

System Configuration

Key configuration files are hosted in the following locations:

  • Shell settings: ~/.bashrc and ~/.config/nushell/
  • Package backends: /etc/lilith/debrep.toml
  • Theme options: /etc/lilith/theme.toml

Post-Installation Check

After installing, you can verify your package status and AI integrations by running the verification diagnostic command:

lilim doctor

The Redirect Repository Pattern

Lilith Linux implements a Redirect Repository (Package Index Overlay) structure. Instead of replicating gigabytes of package storage locally on private servers, Lilith distributes small, compiled .deb installer scripts (wrapper packages) on GitHub Pages.

How Wrappers Work

When you run sudo apt install hellfire:

  • APT downloads a lightweight hellfire.deb metadata wrapper package (only 1–2 KB) from the Lilith server.
  • The wrapper's internal postinst shell script queries the active installer URL from the JSON manifest.
  • It pulls the compiled browser release from GitHub and unpacks it locally, completely transparent to the user.

Hybrid Backend Redirection

Lilith utilizes the stake backend interface. This allows virtual packages to trigger downstream package installations from diverse providers: APT, Flatpak (Flathub), Pacstall, direct AppImages, or custom source compiles.

Security & Hashes

All redirect URLs are verified on download using SHA256 signatures embedded in the package definitions, preventing upstream code tampering or supply-chain compromises.

Stake Utility CLI

stake is the core manager for package redirections. Example commands:

  • stake list: Show all active redirects and overrides
  • stake update: Pull new JSON redirect definitions from the remote index
  • stake install [package-name]: Deploy custom wrapper packages

Lilim Installer CLI

lilim coordinates system-wide installation configurations and validates dependencies:

  • lilim install ai-suite: Configures LLM environments and binds open-interpreter
  • lilim upgrade: Safely updates custom wrappers and theme profiles
  • lilim check-updates: Validates wrapper versions against the overlay server

S8n Prompt Enhancer

s8n configures bash terminal behaviors, prompts, coloring schemas, and system status widgets:

  • s8n apply-theme: Load the cyber-themed terminal prompt
  • s8n status: View system performance metrics dynamically

Vicinae Sync Tool

vicinae handles configuration replication and key syncs across multiple Lilith nodes within a local network.

Splash Boot Animations

Lilith replaces default Ubuntu animations system-wide during startup and shutdown:

  • Boot Video: The full-screen boot screen renders the custom animated lilith-burn-loading.mp4.
  • Loading Spinner: The standard Ubuntu loading circle is replaced with the custom animated webm file lilith-spinner.webm.
  • Branding: The official Lilith Banner (lilith-banner.png) replaces the "Ubuntu" text.

Theme Configuration

The desktop theme utilizes a Uniform Glassmorphism layout. Glass panels with blur backdrops are applied to:

  • Terminal windows and titlebars
  • App launcher dashboards and popups
  • Application control panels

Custom Typography

Lilith Linux seeds custom developer fonts out of the box, including Flame Font, Outfit, and JetBrains Mono Nerd Font, applying them to the editor, shell prompt, and system headers.

Desktop Settings Path

Desktop themes, transparency thresholds, and layout parameters can be customized inside the schema configuration file:

/etc/lilith/theme.toml
